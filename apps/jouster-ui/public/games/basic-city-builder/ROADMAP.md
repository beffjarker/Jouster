# Basic City Builder - Roadmap

## Completed

- [x] 8x8 grid-based city simulation
- [x] Turn-based gameplay with money, population, and day tracking
- [x] Six building types: Road, Residential, Commercial, Industrial, Park, Town Hall
- [x] Building placement with cost and requirement validation
- [x] Income calculation based on building types and road adjacency
- [x] Win condition: reach 100 population
- [x] Lose condition: 5 consecutive days without enough money
- [x] Canvas-based rendering with building icons and grid
- [x] Building selector panel with costs and requirements
- [x] Game status display (money, population, day, income)
- [x] Next Day button for turn progression
- [x] Game over screen with win/lose states
- [x] Unit tests for game logic (Node.js)
- [x] README with game instructions and building statistics
