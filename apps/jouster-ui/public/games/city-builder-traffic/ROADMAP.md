# City Builder & Traffic - Roadmap

## Milestone 1: Core City Building (v1)
- [x] 12x10 grid with road, residential, commercial, industrial, power, water tiles
- [x] BFS power propagation from power plants
- [x] Happiness system based on power, water, and building mix
- [x] Income/expense economy with turn-based advancement
- [x] Win/lose states (happiness thresholds, turn limit)
- [x] Save/load game state
- [x] Keyboard and mouse/touch controls
- [x] Phone-responsive layout
- [x] Test suite (34 tests)

## Milestone 2: Traffic Simulation
- [ ] Vehicle pathfinding along roads between buildings
- [ ] Traffic congestion model affecting happiness and income
- [ ] Vehicle spawning and despawning based on building occupancy
- [ ] Traffic light or intersection logic for complex road layouts
- [ ] Visual vehicle rendering on the canvas

- [ ] Building upgrade paths (residential -> apartment, commercial -> office, etc.)
